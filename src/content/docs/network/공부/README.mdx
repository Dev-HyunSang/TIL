- 학부에서 2학년 1학기 때 수강한 "데이터 통신" 과목에서 `A0`를 받았다.
- 생각보다 배우면서 재밌었고, 어떻게 이러한 통신 규칙을 통일 시켜서 통신하는지에 대한 많은 궁금증과 흥미가 생겼다.
- 주로 TCP/IP 프로토콜, OSI 7계층 모델 등 기초적인 내용에서부터 본 문서는 출발한다.

---

- **1주차:**
    - OSI/TCP-IP 모델
    - 내 IP / Gateway / DNS 확인
- **2주차:**
    - ARP가 왜 필요한지(패킷 흐름으로 확인)
    - 스위치가 MAC 테이블로 전달하는 감각
    - VLAN은 "논리적 분리"라는 한 문장으로 이해
- **3주차:**
    - 3-way-handshake, 포트 개념
    - DNS 질의/응답을 Wireshark로 확인
    - DHCP가 IP를 주는 과정 캡쳐
