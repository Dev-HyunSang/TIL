---
title: "민감한 키를 어떻게 안전하게 관리할 수 있을까?"
---

- Flutter를 사용하여 지하철역/버스정류장 실시간으로 알려주는 앱을 만든 도중 문득 고민이 생김.
    - 만약 JSON 혹은 `.env` 파일로 API 키와 같이 민감한 키를 저장하여 사용함에 있어서 만약 이 앱이 정식적으로 공개되더라도 문제 없는지 등에 관한 고민이 생김.
    - "만약 Reverse Engineering를 통해서 클라이언트에 저장된 키를 읽을 수 있지 않을까?"라는 생각에서도 출발함.

## 그럼 어떻게...?

- 일단 Reverse Engineering 측면에서 봤을 땐 클라이언트(앱)에 이러한 키들이 저장된다면 확인할 수 있다는 단점이 있음.
    - 하지만 개발 편의성은 좋다. 배포 시에 CI/CD를 통해서 `.env` 파일에 키를 넣어주기만 하면 된다는...!
    - [protect secrets in flutter app from reverse engineering](https://stackoverflow.com/questions/72826414/protect-secrets-in-flutter-app-from-reverse-engineering)를 참고했다.
- Flutter 공식 문서에서도 비밀 정보를 저장하는 것은 보안상 좋지 않은 관행이라고 적혀 있다.
    - > It is a poor security practice to store secrets in an app. / [Obfuscate Dart code](https://docs.flutter.dev/deployment/obfuscate)
